# Motion graphics in Remotion

## Why Remotion

- Shots are React components and frames are pure functions of `useCurrentFrame()`.
- `remotion studio` gives a scrubbable preview.
- `remotion still` gives single frames for review.
- The renderer muxes audio.
- Both illustration and rough.js hand-drawn videos are built this way.

## Set up a project

```bash
cp -R <skill>/templates/remotion-starter ~/Motion/<video-slug>
cd ~/Motion/<video-slug> && npm install
tools/sync_vo.sh "<path>/Projects/<视频标题>"     # copies VO wavs → public/vo, timeline.json → src/
npx remotion studio src/index.js
```

Record the motion-project path and the Remotion version in the storyboard's locked decisions.

## Files

| File | Role |
|---|---|
| `src/theme.js` | Design system: palette `C`, fonts, `FPS`, `W`, `H`. Shots use only these tokens. |
| `src/timeline.json` | From `assemble_vo.py`: every shot's `start` and `duration`, and every line's `start`, `end` and `file`. **The only source of timing.** |
| `src/Video.jsx` | Lays out one `<Sequence>` per shot, one `<Audio>` per VO line, the background, and burned-in subtitles (≤ 18 characters per cue, matching the SRT). |
| `src/shots/index.js` | Shot-ID → component registry. Unregistered shots render a placeholder showing the ID, so the whole cut plays from day one. |
| `src/shots/sN.jsx` | Shot components, grouped a few scenes per file. Each gets `L`, the shot's lines with times relative to the shot, and `dur`. |
| `src/lib.js` | `useSec`, `prog(t,a,b,ease)`, `within(line, frac)`, `useSpring`, `EASE` / `EASE_IN_OUT`, seeded `rng`. |
| `src/components/rough.jsx` | Hand-drawn primitives: `R` (any rough shape, drawn on), `Canvas`, `Arrow`, `Hand`, `Highlight`, `Circle`, `Cross`, `Check`, `Phase`, `usePop`, `Sfx`. |
| `src/components/PostCard.jsx` | Real social-post card plus a deleted-post card (see `social-post-cards.md`). |
| `tools/make_sfx.py` | Synthesizes SFX into `public/sfx/` (tape, paper, stamp, thud, crack, scribble, pop, ding, tick, boing, rumble, zap, boom). The sounds are generated by code, so there are no licensing issues. |
| `tools/stills.mjs` | Bundles once and renders many stills: `--shots [frac]` gives one frame per shot (a contact sheet); `S5-01@10` gives 10 s into S5-01. |

## Writing a shot

```jsx
export const S3_02 = ({ L }) => (
  <>
    <Phase to={L[1].start - 0.2}>            {/* part 1 lives while sentence 1 is spoken */}
      <Canvas>
        <R kind="rectangle" a={[560, 300, 800, 420]} at={0.1} dur={0.6} seed={1} />
        <Circle cx={960} cy={510} w={300} h={180} at={within(L[0], 0.6)} />
      </Canvas>
    </Phase>
    <Phase from={L[1].start - 0.1}> … </Phase>
    <Sfx at={within(L[0], 0.6)} name="pop" volume={0.35} />
  </>
);
```

- **Tie every cue to a line.** Use `L[i].start`, `L[i].end`, or `within(L[i], frac)` for the point where a key word lands. Shots then follow VO retakes automatically.
- **Split shots with `Phase`.** A shot with several sentences usually has one beat per sentence: fade in at the sentence, fade out before the next.
- **Keep seeds stable per element,** so the layout doesn't jump between renders.
- **Camera.** Use a slow push-in (`scale: 1 + t*0.006`) or a gentle pan. Don't punch-zoom on every line.
- **Put SFX next to the motion that causes it.** Keep volumes low: scribble 0.25, pop 0.35, tape 0.5.

## Review loop

1. Make a **contact sheet:** `node tools/stills.mjs out/sheet --shots 0.6`, then look at every shot's frame before rendering video.
2. **Spot checks:** `node tools/stills.mjs out/check S6-04@3.5 S6-04@12`.
3. **Short clip:** `npx remotion render src/index.js Draft out/clip.mp4 --frames=0-300`.
4. **Full draft,** in the background: `npx remotion render src/index.js Draft "<project>/Drafts/<title>_draft_v1.mp4" --codec=h264 --crf=18 --audio-bitrate=320k`.
5. **Check the file:** ffprobe the duration (it should equal `timeline.total`), check levels with `ffmpeg -af volumedetect` (no clipping, no silent stretches), and sample frames.
6. **Covers:** add `<Still>` compositions (16:9 1920×1080 and 4:3 1440×1080 are common platform requirements). Stills render at frame 0, so draw everything with a negative `at`.

## Gotchas

- Use `OffthreadVideo` for embedded clips. Mute third-party clips that contain music.
- `staticFile()` paths are relative to `public/`. Re-run `sync_vo.sh` after every `assemble_vo.py`, or the audio and timeline drift apart.
- Keep the rough.js path cache bounded (≈ 6000 entries) or long renders grow memory.
- Load fonts from the system (macOS PingFang SC / Hannotate SC). Check that the render machine has them.
